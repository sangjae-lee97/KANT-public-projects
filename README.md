# KANT Public Projects

KANT 과정에서 진행한 공개 프로젝트를 정리하는 인덱스 저장소입니다.

## Projects

### KANT AX Agent Study

- Repository: https://github.com/sangjae-lee97/kant-axagent-study
- Visibility: Public
- Purpose: KANT AX Agent 과정에서 진행한 학습 및 실습 프로젝트
- Notes: 실제 코드, 커밋, 과제 제출 및 개발 이력은 원본 저장소에서 관리합니다.

## 운영 원칙

- 이 저장소에는 각 프로젝트의 코드를 복사하지 않습니다.
- 실제 코드는 개별 프로젝트 저장소에서 관리합니다.
- 공개 가능한 KANT 프로젝트만 이 인덱스에 정리합니다.
- 튜터님에게 과제를 제출할 때는 각 프로젝트의 원본 저장소 또는 필요한 파일/PR 링크를 사용합니다.
- 프로젝트가 추가되면 이 README에 링크와 간단한 설명을 추가합니다.
