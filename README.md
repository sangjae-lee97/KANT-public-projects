## 📌 운영 원칙

- 이 저장소는 **프로젝트 인덱스** 역할만 합니다.
- 실제 소스코드는 각 원본 저장소에서 독립적으로 관리합니다.
- **Study**에는 수업·실습·과제·학습용 저장소를 정리합니다.
- **Projects**에는 독립적으로 진행한 프로젝트를 정리합니다.
- 과제 제출 시에는 해당 원본 저장소, 파일 또는 PR 링크를 사용합니다.
- 새로운 공개 저장소가 생기면 성격에 따라 Study 또는 Projects에 추가합니다.
