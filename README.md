## 운영 원칙

- 이 저장소에는 각 프로젝트의 코드를 복사하지 않습니다.
- **Study**에는 수업, 실습, 학습용 저장소를 정리합니다.
- **Projects**에는 독립적으로 진행한 KANT 프로젝트를 정리합니다.
- 실제 코드는 각 원본 저장소에서 관리합니다.
- 튜터님에게 과제를 제출할 때는 해당 원본 저장소 또는 필요한 파일/PR 링크를 사용합니다.
- 새로운 공개 저장소가 생기면 성격에 따라 Study 또는 Projects에 추가합니다.
